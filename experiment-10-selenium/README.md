# Experiment 10 — Selenium installation and first test
**Aim:** Install and explore Selenium WebDriver using Java.
Install JDK 17+, Maven, Chrome. Run `mvn test` from this folder; Selenium Manager normally downloads/manages the driver automatically (network required).
The test opens https://example.com/ and validates the page title.
**Evidence:** `mvn test` output showing 1 test passed. Chrome must be installed.
