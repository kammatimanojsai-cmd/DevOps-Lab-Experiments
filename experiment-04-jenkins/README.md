# Experiment 4 — Install and explore Jenkins
**Aim:** Set up Jenkins and explore dashboard, credentials, plugins, build history.
1. Install a compatible JDK and Jenkins from https://www.jenkins.io/doc/book/installing/ .
2. Start the Jenkins service on Windows in Services, then open http://localhost:8080 .
3. Complete setup wizard, install recommended plugins, create administrator user.
4. Create a Freestyle or Pipeline job; run a build.
5. Open build history and Console Output.
**Evidence:** Jenkins dashboard, Manage Jenkins, jobs page, successful console output.
Do not upload administrator passwords, unlock keys, or credentials to GitHub.
