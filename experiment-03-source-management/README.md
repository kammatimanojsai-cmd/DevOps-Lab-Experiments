**Aim:** Upload and maintain source code from Experiment 1 on GitHub.
1. From the project root, check `git status`.
2. Add Experiment 1: `git add experiment-01-registration`.
3. Commit: `git commit -m "Add experiment 1 registration app"`.
4. Push: `git push origin main` after you have configured your remote.
5. Confirm the files appear under `experiment-01-registration` on GitHub.
6. Edit the HTML page, commit again, and show GitHub commit history.
